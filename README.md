# MATCHA — Multi-Agent Conversational Game Recommendation (Production)

A production-grade, multi-agent conversational recommender system (CRS) for the
Roblox games domain, implementing the MATCHA framework from:

> *Toward Safe and Human-Aligned Game Conversational Recommendation via
> Multi-Agent Decomposition* (arXiv:2504.20094)

The pipeline decomposes a free-form recommendation request into five specialized
agents plus a safety guardrail:

```
User request
   │
   ▼
Risk Control (input guardrail: RA-LLM + CoT jailbreak detection)
   │
   ▼
Intent Parsing  ──►  Retrieval (ChromaDB semantic search + metadata filters)
   │                    │
   ▼                    ▼
Multi-LLM Ranking (critic/advocate debate + consensus)  ──►  Explanation
   │
   ▼
Risk Control (output alignment verification)
   │
   ▼
Final recommendation (or BLOCKED / NO_MATCHES)
```

## Features

- **5 agents**: `risk_control`, `intent`, `retrieval`, `ranking`, `explanation`
- **ChromaDB** persistent vector store with metadata filtering + time-decay popularity boost
- **FastAPI** REST gateway (`/api/v1/recommend`, `/metrics`, `/health`, `/admin/sync-catalog`)
- **Celery + Redis** background catalog ingestion (RAWG)
- **Streamlit** chat UI + **Prometheus** agent-latency metrics
- **Docker Compose** for the full backend/worker/frontend/prometheus stack
- **DeepSeek** LLM backend (`deepseek-v4-pro`) — see `llm_client.py`

## Quick start (local, without Docker)

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Set your DeepSeek API key
export DEEPSEEK_API_KEY="sk-..."

# 3. Run the unit test
pytest test_pipeline.py

# 4. End-to-end smoke test (uses an in-memory vector store)
python smoke_test.py

# 5. Start the API (seeds the catalog from data/omulet/ on first run)
uvicorn app:app --reload
#   GET  /health
#   POST /api/v1/recommend  {"user_id": "u1", "prompt": "I want an immersive strategy game on PC."}
```

## OMuleT dataset

MATCHA evaluates on **OMuleT** (553 real Roblox requests, 2,074 games;
arXiv:2411.19352). That dataset is Roblox-internal and **not publicly released**.

This repo ships a **schema-exact synthetic stand-in** under `data/omulet/`
(`game_catalog.csv` + `requests.json`), generated by `generate_omulet_data.py`
so the full pipeline runs out of the box. To use the real data, drop the official
files into `data/omulet/` with the same schema — no code changes required.

```bash
# regenerate the stand-in from scratch
python generate_omulet_data.py

# offline Hit@K benchmark (small --limit for a quick run)
python benchmark.py --limit 5 --k 5
```

> Note: ChromaDB uses an ONNX MiniLM embedding model and downloads ~80 MB on the
> first run (cached under `~/.cache/chroma/`).
